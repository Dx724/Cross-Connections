# Cross Connections

A sixteen-word puzzle with four categories across and four categories down.

Select a row or column using its triangle, then check the selection. Correct groups remain intact while tiles can still move within them. Three incorrect checks ends the game.

## GitHub Pages

Publish from the `main` branch and `/docs` folder. The site is buildless HTML, CSS, and JavaScript.

## Development

Edit files in `docs/`. Run `node tests/game.test.cjs` for game logic checks.

This repository uses the development version and is independent of the original ChatGPT-hosted site.
